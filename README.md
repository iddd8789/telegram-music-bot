# بوت مزيكا تلجرام 🎶

بوت بيعمل حاجتين:

1. **يوت + اسم الأغنية** → البوت يدور على الأغنية في يوتيوب ويبعتها أوديو في الشات (شغال في الجروبات والخاص).
2. **تشغيل + اسم الأغنية** → لو فيه مكالمة صوتية مفتوحة في الجروب، حساب مساعد يدخل المكالمة ويشغّل الأغنية كاملة. وفيه كمان **تخطي** (عدّي الأغنية الحالية) و **إيقاف** (وقف التشغيل وامسح الطابور).

كله مجاني ١٠٠٪: الكود والمكتبات والتشغيل.

---

## الملفات

| الملف | إيه دوره |
|---|---|
| `bot.py` | كود البوت نفسه |
| `gen_session.py` | بتشغله مرة واحدة عشان تطلع نص السيشن للحساب المساعد |
| `requirements.txt` | المكتبات المطلوبة |
| `.env` | إعدادات البوت (التوكن موجود فيه خلاص) - **ملف سري، متبعتوش لحد** |
| `.env.example` | نموذج فاضي للإعدادات |

## خطوات التشغيل على جهازك

### الخطوة 1: ثبّت بايثون و ffmpeg

- **بايثون**: نزّله من [python.org/downloads](https://www.python.org/downloads/) (نسخة 3.11 أو أحدث). أثناء التثبيت على ويندوز، علّم على المربع **Add python.exe to PATH** - دي مهمة جداً.
- **ffmpeg**:
  - ويندوز: افتح CMD واكتب `winget install ffmpeg` وبعدين اقفل CMD وافتحه تاني.
  - لينكس: `sudo apt install ffmpeg`
  - ماك: `brew install ffmpeg`

اتأكد إنهم شغالين: افتح CMD (أو Terminal) واكتب `python --version` و `ffmpeg -version`. لو طلعوا أرقام نسخ يبقى تمام.

### الخطوة 2: ثبّت المكتبات

افتح CMD جوه فولدر المشروع واكتب:

```
pip install -r requirements.txt
```

### الخطوة 3: هات API_ID و API_HASH (مجاني، دقيقتين)

1. افتح [my.telegram.org](https://my.telegram.org) وسجّل دخول برقم تلجرام بتاعك (هيجيلك كود على تلجرام).
2. ادخل على **API development tools**.
3. اعمل App جديد: اكتب أي اسم (مثلاً `musicbot`) وأي وصف مختصر.
4. هتلاقي رقمين اسمهم **api_id** و **api_hash**. انسخهم وحطهم في ملف `.env` مكان السطرين الفاضيين:

```
API_ID=12345678
API_HASH=abcdef1234567890abcdef1234567890
```

### الخطوة 4 (عشان ميزة التشغيل في المكالمات): الحساب المساعد

الميزة دي محتاجة **حساب تلجرام تاني** (أي رقم موبايل تاني عندك). ده الحساب اللي هيدخل المكالمة ويشغّل المزيكا.

1. اعمل حساب تلجرام بالرقم التاني لو معندكش.
2. شغّل الأمر ده على جهازك:

```
python gen_session.py
```

3. هيسألك عن API_ID و API_HASH (نفس اللي من الخطوة 3)، وبعدين رقم موبايل الحساب المساعد بالكود الدولي (مثلاً `+2010xxxxxxxx`)، وبعدين كود التحقق اللي هيوصل على تلجرام، ولو الحساب عليه تحقق بخطوتين هيطلب الباسورد.
4. في الآخر هيطلعلك نص طويل - ده **SESSION_STRING**. انسخه وحطه في `.env`:

```
SESSION_STRING=BQAAAA...النص الطويل...
```

> النص ده زي الباسورد بالظبط: أي حد معاه يقدر يتحكم في الحساب المساعد. متبعتوش لحد.

> لو مش عايز الميزة دي دلوقتي، سيب SESSION_STRING فاضي - البوت هيشتغل عادي بميزة "يوت" بس.

### الخطوة 5: شغّل البوت

```
python bot.py
```

لو كتب `Bot client started.` يبقى شغال ✅

### الخطوة 6: ضيف البوت للجروب

1. ضيف البوت (@music_marwan_bot) للجروب.
2. ضيف **الحساب المساعد** كمان للجروب (عشان يقدر يدخل المكالمة).
3. افتح مكالمة صوتية في الجروب واكتب: `تشغيل وصل الغول`

ملاحظة: خاصية قراءة رسايل الجروب (Privacy Mode) متعطلة عند البوت خلاص، فهيشوف أوامر "يوت" و"تشغيل" عادي. لو حصل ومردش على الأوامر في جروب، شيله من الجروب وضيفه تاني.

---

## الأوامر

| الأمر | بيعمل إيه |
|---|---|
| `يوت اسم الأغنية` | ينزّل الأغنية من يوتيوب ويبعتها أوديو في الشات |
| `تشغيل اسم الأغنية` | يشغّل الأغنية في المكالمة الصوتية المفتوحة (ولو فيه أغنية شغالة، يضيفها للطابور) |
| `تخطي` | يعدّي للأغنية اللي بعدها في الطابور |
| `إيقاف` | يوقف التشغيل ويمسح الطابور ويخرج من المكالمة |

الأسماء بالعربي والإنجليزي شغالة.

## تشغيله ٢٤ ساعة مجاناً

- **أسهل حاجة: جهازك.** طول ما الجهاز شغال والبوت مفتوح، البوت شغال. مناسب جداً في الأول.
- **سيرفر مجاني للأبد:** Oracle Cloud عندها خطة Always Free فيها سيرفر صغير مجاني مدى الحياة. تسجّل في [oracle.com/cloud/free](https://www.oracle.com/cloud/free/)، اعمل سيرفر لينكس (VM)، وبعدين نفس خطوات التشغيل فوق عليه (`apt install python3 ffmpeg` وبعدين `pip install -r requirements.txt` وشغّل `python bot.py`). عشان يفضل شغال بعد ما تقفل الـ SSH شغّله بـ `nohup python bot.py &` أو اعمله service.
- **تحذير:** منصات زي Railway وRender كانت مجانية بس دلوقتي الخطة المجانية محدودة جداً أو بتفصل بعد شوية، فالأفضل جهازك أو Oracle المجاني.

### ملاحظة مهمة عن يوتيوب

يوتيوب بيعمل حظر مؤقت للسيرفرات السحابية أحياناً (هتشوف رسالة "Sign in to confirm you're not a bot" في اللوج). على جهازك الشخصي الموضوع ده نادر. لو ظهر في الاستضافة السحابية، الحل الشائع هو تمرير كوكيز لـ yt-dlp - لو حصلتلك ابعتلي وأنا أظبطهالك.

## مشاكل شائعة

- **`Missing environment variables`** → نسيت تملأ API_ID أو API_HASH في `.env`.
- **`ffmpeg: command not found`** → ffmpeg مش متثبت صح، راجع الخطوة 1.
- **البوت مش بيرد في الجروب** → شيل البوت من الجروب وضيفه تاني (عشان تتطبق إعدادات الخصوصية الجديدة).
- **`NoActiveGroupCall`** → لازم تفتح مكالمة صوتية في الجروب الأول قبل ما تكتب تشغيل.
- **الحساب المساعد مش بيشغّل** → تأكد إنه عضو في الجروب وإن SESSION_STRING صحيح.
